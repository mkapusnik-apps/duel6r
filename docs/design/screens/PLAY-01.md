# PLAY-01 — Local arena parity reference

Functional authority: [PLAY-01](../../screens/play-fullscreen.md), PRES-ARENA-001–012 / PRES-ARENA-AC-001–005, ENV, BON, PLY, CMB and UI live-play requirements. Structural authority: [PLAY-01](../wireframes/PLAY-01/PLAY-01.svg). Appearance authority: [Local and network arena parity](../../design.md#local-and-network-arena-parity), UX-ARENA-001–026.

Local Play remains the appearance reference. The new low-fidelity diagram records existing world anchors, whole-level allocation and HUD relationships; it does not replace the actual local appearance with a schematic or alter local behavior. Equivalent network states must restore local water, object attachments, projection/depth, animation, effects and HUD. Local profile customization is not imported into network play.

The single supported desktop structure spans the existing 850 × 700 floor, 1280 × 720 short-wide, 1280 × 900 representative and 1920 × 1080 scale checks. Camera framing adapts to the full client; world positions are not menu-canvas coordinates. Existing local keyboard/controller assignments and noninteractive HUD regions remain unchanged.

The [coordinated matrix](../screenshots/README.md#arena-parity-and-shared-final-presentation) supplies a current local reference and a comparable real network view. Existing local images are appearance context, not captures of the eventual candidate. The temporal supplement is required for water motion and changing effects; static images alone cannot accept those criteria.
